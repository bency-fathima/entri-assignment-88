# 🍽️ Restaurant Menu Website

A restaurant menu webpage created using **HTML5 and CSS3** as part of a frontend web development assignment.

The project presents a restaurant’s menu in a clean, elegant layout with categorized food items, descriptions, prices, an About Us section, and contact information.

## 📋 Assignment Overview

**Assignment:** Create a restaurant menu page using HTML5 and CSS.

The goal of this project is to practice HTML5 structure, semantic elements, CSS styling, typography, colors, spacing, and the CSS box model.

## ✨ Features

* Proper HTML5 boilerplate
* Meaningful page title and charset meta tag
* Header with:

  * Restaurant name
  * Short tagline
  * Navigation links
* Three menu categories:

  * Starters
  * Main Course
  * Desserts
* Three menu items in each category
* Food cards containing:

  * Item name
  * Short description
  * Price
* About Us section with the restaurant’s story
* Footer containing:

  * Restaurant address
  * Opening hours
  * Copyright information
* Hover effects for interactive menu cards
* Google Fonts for improved typography
* Warm color palette and structured layout

## 🛠️ Technologies Used

* **HTML5** — Semantic page structure and content
* **CSS3** — Styling, layout, colors, spacing, borders, and hover effects
* **Google Fonts** — Playfair Display and Poppins
* **Unsplash** — Food imagery
